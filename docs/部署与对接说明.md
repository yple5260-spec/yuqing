# 部署与对接说明

## 1. 架构与部署边界

浏览器原生HTML/CSS/JS → 同源JSON API → Python单实例服务 → SQLite WAL + 加密证据文件。

业务档案/历史、导入预览和导出文件用Fernet加密；图片保留原始字节后加密，读出时核对SHA-256。规则、证据元数据URL、账号名和审计不作字段加密，因此**不是全库加密**。本地密钥与数据库同机只降低离线误读风险，不防持有主机权限的攻击者。系统没有外部AI请求，也不任意请求用户输入的网址。

受控试点建议仅绑定127.0.0.1，由内网TLS反向代理接入；网关限流、请求体限制、Host透传与安全响应由运维核查。不要把内置HTTP服务器直接公开；未经压测不能承诺并发能力/可用性指标。每个数据目录仅允许一个进程，不能直接用多worker或共享SQLite实现横向扩容。

其他省份建议单独部署、独立数据目录、独立密钥和业务审批。当前无省级租户行权限/全集团主数据对齐功能。

## 2. 环境变量

| 变量 | 默认 | 说明 |
|---|---|---|
| XIN_DATA_DIR | 本目录/data | 绝对路径，受控磁盘；运行账号最小权限 |
| XIN_HOST | 127.0.0.1 | 监听地址；内网代理场景优先仍回环绑定 |
| XIN_PORT | 8765 | 服务端口 |
| XIN_ALLOWED_HOSTS | 127.0.0.1,localhost | 请求Host精确主机名白名单，英文逗号分隔；通过代理时须配置实际Host |
| XIN_SECURE_COOKIE | 未设 | TLS代理场景设1，Cookie加Secure；本机HTTP不设，否则浏览器可能不发送Cookie |
| XIN_ENCRYPTION_KEY | 未设 | 已托管的Fernet密钥；不设则首次生成data/encryption.key，不能丢失/随意更换 |
| XIN_PYTHON | 未设 | 启动脚本指定Python位置 |

首次登录凭据写入data/首次登录凭据.txt，使用后应按企业密码交接流程妥善移交并清理过期明文凭据文件。修改密码不会重写该文件。系统不发送/显示明文业务密码，不在日志记录请求体、Cookie或查询参数。

## 3. 账号权限与复核

- admin：规则发布、账号管理、操作审计；初始admin同时含analyst/exporter/viewer，不含reviewer。
- analyst：建档、修改、上传、导入、辅助摘要。
- reviewer：独立复核、覆盖申请和独立审批；不是创建人/历史修改人。
- exporter：正式CSV与脱敏报表、批次下载、人工回执。
- viewer：登录查询与证据查看，手机号接口脱敏。

多角色可组合，但自己创建或编辑过的档案不能自审；覆盖申请不能由申请人/档案创建修改人审批。Session 8小时，停用/改角色/改本人密码撤销相关会话。账号连续失败5次锁15分钟，IP连续20次失败锁15分钟。首次上线仍应接入企业SSO/MFA，不把本地账号机制当成全企业IAM。

## 4. API清单

全部 `/api/*` 除登录需Cookie会话；写接口要求 `X-CSRF-Token`，不开放跨域。JSON请求体最多20MB，图片本体最多12MB/4000万像素。错误返回 `{error:说明}`；401未登录、403无权限/CSRF、409版本冲突、422业务校验失败。

| 方法 | 路径 | 作用 |
|---|---|---|
| GET | /health | 健康与版本（不含数据） |
| POST | /api/login /api/logout /api/password | 登录/退出/本人密码 |
| GET | /api/me | 当前角色、CSRF |
| GET/POST | /api/accounts | 账号列表/创建 |
| PUT | /api/accounts/{账号} | 权限/启用调整，撤销会话 |
| GET/POST | /api/rules | 读取/发布新规则，发布带expected_version和note |
| GET/POST | /api/cases | 查询/创建事件档案 |
| GET/PUT | /api/cases/{id} | 详情/修改，修改带expected_version |
| GET | /api/cases/{id}/history | 历史版本摘要（不是明文历史数据库导出） |
| POST | /api/cases/{id}/evidence | 上传图片：base64 data、source_url、captured_at、note、expected_version |
| GET | /api/evidence/{id} | 鉴权后图片原始字节，摘要验证 |
| POST | /api/cases/{id}/review | expected_version、rule_version、level、note；需覆盖时override=true |
| GET/POST | /api/overrides、/api/overrides/{id} | 申请列表 / 独立审批approve、note |
| POST | /api/cases/{id}/summary | 本地模板摘要，external_ai=false |
| POST | /api/import/preview | format=csv,text；或format=xlsx_h,data(base64) |
| POST | /api/import/commit | 本人预览批次id，只能提交一次 |
| GET/POST | /api/exports | 批次列表/生成，kind=formal或masked、purpose、authorized |
| GET | /api/exports/{id}/download | 下载审计；不标为同步完成 |
| POST | /api/exports/{id}/receipt | 人工回执sha256、accepted、reference，全量摘要和条数须一致 |
| GET | /api/audit | 最近500条及全链摘要校验，管理员可见 |

metrics结构：`posts7/rate/fans/original30/bigv` → `{value,evidence:[证据ID],observed_at:含时区ISO时间,basis:核验依据,pair:{ids:[前ID,后ID],totals:[前累计,后累计]}}`；pair仅用于rate。未采集值为null，不是0。档案修改和上传均产生新版本，需刷新后继续操作。

## 5. 客服系统对接约定（待目标方确认）

导出格式UTF-8 BOM CSV，每行是**事件档案**，不是跨事件合并用户。字段可见“客服导出字段映射.csv”。关键规则：

1. 正式CSV只含当前规则/记录版本下、手机号已核实、独立人工复核已确认的结果。
2. 最终等级为“红色/橙色/黄色/蓝色”中文值；目标系统内部编码暂不自定。目标方如需R/O/Y/B，需先确认字典及映射。
3. 得分可能为区间（部分指标未知但人工审批定级），保留上下界与逐项依据，不伪造唯一分数。
4. 域内等级沿用输入的已有标签；不重算、不擅自决定域内×域外综合等级。
5. 建议业务幂等键为档案编号+档案版本+规则版本；一个手机号多事件如何聚合，由目标方业务规则决定，当前不自动取最高等级覆盖其他事件。
6. 当前回执仅支持**整批全量接受**的人工登记，需文件完整SHA-256+成功条数+回执号。目标方部分成功/逐行拒绝/API回推、撤销或增量同步还未实现，不能凭本地状态声称目标成功。
7. 导出文件为授权业务使用的明文，离开系统后需受控传输、访问控制、保留和清理。服务端保存的批次文件为加密状态。

## 6. 停机备份与恢复

停止服务（Ctrl+C）后：

```sh
python3 manage.py backup /受控路径/换芯计划备份.zip
python3 manage.py verify-backup /受控路径/换芯计划备份.zip
```

备份包含一致性SQLite副本、加密证据及本地密钥；不含初始密码文件，备份副本移除Session。实例锁防止运行时备份；备份压缩包本身**未额外加密**，且若含密钥可解密业务资料，必须存放受控加密介质。环境变量提供的密钥不在zip中，须另行受控托管。

恢复：先停止服务并保留现有数据；在新建受控空目录解压经摘要核验的备份，配置XIN_DATA_DIR至该目录。使用原密钥（文件或环境变量）启动后，核对档案数、快照摘要、复核/导出版本、审计链，再做业务验收。不要将不可信备份解压覆盖程序或其他文件。丢失密钥将无法恢复；本版无在线密钥轮换功能。

目前未提供网页删除/到期清理功能，试点前须业务确定保留期和授权删除流程，由受控运维执行；生产上线需补齐审批、删除传播范围和备份清理机制。哈希链只是本机一致性检查，不具备独立可信时间戳或对抗主机管理员篡改的能力。

## 7. 生产上线前必须补齐

- 数据处理范围、手机号来源、岗位授权、证据保留期限获得业务和安全批准。
- 确认评分阈值，不以维权身份推断动机，不改变用户服务权益。
- 接入企业账号/离职停权、HTTPS、网关、集中日志、密钥托管与备份告警。
- 按实际用户量完成容量/并发/故障恢复/安全渗透测试。
- 新客服真实字段、等级字典、用户/事件粒度、幂等和回执协议联调通过。
- 若接AI或自动采集：明确授权平台、模型部署位置、脱敏字段、超时/失败/人工复核策略，禁止以模拟结果冒充真实调用。
