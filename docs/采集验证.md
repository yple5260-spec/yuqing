# Crawl4AI本地验证

本阶段使用Python库，不使用Docker、不接管现有业务服务。采集环境独立放在Git忽略的runtime/crawl4ai-venv；业务.venv及requirements.txt保持原样。

在仓库根目录使用Python 3.11+建立环境并安装：

```powershell
uv venv runtime/crawl4ai-venv --python .venv/Scripts/python.exe
uv pip install --python runtime/crawl4ai-venv/Scripts/python.exe --index-url https://pypi.tuna.tsinghua.edu.cn/simple -r requirements-crawler.txt
.\runtime\crawl4ai-venv\Scripts\python.exe -m playwright install chromium
.\runtime\crawl4ai-venv\Scripts\python.exe scripts/crawl4ai_smoke.py
```

镜像缺包时安装命令改用官方索引https://pypi.org/simple。当前固定Crawl4AI 0.9.5；不安装torch或transformer可选扩展，不配置模型凭据。官方安装方式见https://docs.crawl4ai.com/core/installation/。

验证脚本会临时启动一个只监听127.0.0.1的页面，等待JavaScript更新内容，再检查正文提取和截图图片可解码。结束后自动停止测试页面；结果保存至runtime/crawl4ai-smoke中的page.md、screenshot.png和result.json。脚本不加载.env、不导入业务server.py，也不访问数据库或S3。

## 本地操作

新建档案只填写舆情原文链接、手机号、用户姓名。服务端生成事件编号、识别平台，保存待核实档案并登记后台采集任务；关闭页面不影响执行，采集失败或访问受限不删除档案。标题和发布时间取得原文后自动补充，姓名、手机号不推断为已核实绑定。其它字段在已有档案的“编辑 / 补充指标”中按需维护，原详细建档API兼容保留。批量导入及任务管理见[批量导入与采集任务](批量导入与采集任务.md)。

安装上述独立采集环境后，进入“用户档案”或“快照证据库 → 查看档案”，管理员和录入员可以点击“采集原文与快照”。支持已登记问政平台和微博公开原文的HTTPS详情链接。微博支持 weibo.com/2/detail/数字ID、weibo.com/作者UID/微博ID或短ID、m.weibo.cn/detail/数字ID 和 m.weibo.cn/status/短ID；分享查询参数在访问原文时会去除，短链和作者主页不作为原文建档链接。采集成功后自动补充平台、标题和可确认的发布时间，在档案展示昵称、正文摘要及缺失指标说明，整页原始截图进入现有加密证据库。保存会产生新版本，原复核失效，历史证据继续保留。

访问验证、网络失败或结构变化会自动结束并记录审计，页面展示失败原因，不生成成功快照、不派发人工验证码任务。当前不自动重复请求受限平台，避免持续无效采集。当前为点击触发、单任务运行，75秒进程上限，不含定时调度、批量自动补采、登录态管理或验证码自动处理。

业务服务使用collection.py调用独立Python进程；子进程环境不携带数据库、S3、模型凭据，不读取.env。可通过XIN_CRAWLER_PYTHON指定已安装采集依赖的解释器，默认runtime/crawl4ai-venv。业务镜像只包含轻量调用模块，没有安装浏览器；本次采集按本地非Docker方式运行。

网络阶段不持有档案数据库锁。入库前再次验证发起账号权限和档案版本，遇并发编辑拒绝覆盖；截图继续使用现有加密、SHA-256、审计与存储流程（本地或既有S3配置）。新增 collection_jobs 表保存队列、批次和执行状态；任务结果明细加密保存。

本机业务服务仍使用runtime/local-preview-current.txt指向的隔离数据副本。采集复测结果仅存runtime/platform-probe；本次未向平台生产数据库或S3写入采集数据。

## 微博未登录接入（2026-11-15）

微博已接入相同的三项建档和已有档案采集入口。原文卡片截图进入现有加密证据库；作者UID、昵称、公开精确粉丝数、认证信息和转评赞存入加密档案。两个来源分别记录采集时间：详情页渲染字段、主页自然请求返回的公开资料字段。字段摘录以规范JSON字符串和SHA-256保存，可核对摘录内容；此摘要对应字段摘录，不等于整份HTTP原始响应摘要。

页面明确显示“部分字段待核实”。当前样本只显示月日时分，完整发布时间保持空；不覆盖人工补充的已知完整时间。未登录近7天时间线受限，数量和频次保留null。粉丝数或其它公开账号资料不自动填入计分维度，不自动核实录入姓名、手机号和微博作者的绑定关系。

作者资料请求失败时保留已取得的原文和截图，粉丝数显示待核实。重复采集若图片未变，复用已有截图并保存新的字段观测版本，原证据留存时间保持不变。相同微博的不同域名或分享链接形式在建档时按微博ID去重。

本轮只使用全新匿名浏览器会话；微博正常的游客初始化跳转仅允许官方游客路径和当前已允许的原文/主页目标，所有浏览器HTTP请求仍拒绝私网地址。未增加账号登录、持久化会话或验证码处理。
