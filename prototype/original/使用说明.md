# 外部舆情评估系统 · 演示使用说明

打开同目录 index.html 即可运行；也可通过本机预览 http://127.0.0.1:8769/index.html 查看。页面内嵌 Vue 运行时和样式，不需安装或构建。单文件是演示交付，不含正式后端。

## 汇报与需求评审

首页为研判调度台，展示用户事件数、待复核、待补证/核实、同步任务，以及当前有效已确认结果的风险分布。统计分母和已纳库范围在页面标明。点击数量或等级查看相关明细；关键词、平台、评估状态支持组合查询。

右下角“隐藏需求说明”进入全屏汇报模式。展开后左侧为可操作系统、右侧为对应菜单PRD；点编号可定位说明。“编辑需求说明”后修改自动存于当前浏览器；权限表后三列故意留空供业务评审填写。编辑后点“导出 HTML”，把导出文件交回Agent合并；浏览器缓存不会自动写回原文件。不要直接编辑运行中的左侧DOM。

## 推荐演示路径

1. 周女士 / 宽带移机：65分橙色，初始待复核。顶栏切换李悦（业务复核），打开复核办理、填写意见并通过；进入同步，切换王磊（同步操作）生成任务；登记目标记录号、时间与说明后进入待核对；切回李悦完成核对，才是已同步。
2. 刘先生 / 套餐账单：40–70分跨档，证据不足。进入证据查看单快照，互动速率为未知；不得直接确认等级。
3. 陈女士 / 携号转网：80–95分同为红色，粉丝未知，仍保留证据有限提示；其他门槛满足后可以复核。
4. 赵先生 / 宽带速率：绑定存在争议；需要业务复核人员填写核验依据，不能直接形成正式结果。
5. 吴女士 / 退订计费：初始已同步。以业务复核人员解除错绑，旧结果保留、任务进入待更正；同步人员登记目标更正回执后进入更正待核对，再由业务复核人员核对关闭。

六个菜单共用同一选中用户事件，事件编号、用户、手机号脱敏值及版本保持可见。角色切换使用稳定构造人员ID，仅为演示，不是生产身份认证。

## 新增与补证

以张敏（录入采集）录入事件/链接，先建立待核实记录；以李悦核实绑定后，可由张敏补充内容摘要、发布时间及指标快照。互动频率要求同一批内容两次快照，间隔24小时±30分钟。本演示固定评估时点为2026-10-29 10:00北京时间，补证需使用此前的构造历史时间。新增快照必须晚于该内容已有快照。

批量导入在“链接与绑定”中使用制表符分隔的7列文本；提供构造样本，逐行显示成功、重复或失败，不回滚成功行。构造链接不访问外网；短链跳转解析、附件上传、真实平台自动采集和生产规则发布均未在本次演示中实现。

## 保存、导出与重置

业务操作和PRD编辑分别保存于当前浏览器。完整HTML导出包含当前业务状态、菜单和PRD，使用独立缓存key，重开可继续操作。缓存被清理时可能丢失未导出的操作；存储失败会提示导出。http预览和file直接打开不同源，缓存互不共享。

规则与审计页面中，切换陈晨（规则管理），确认后可以重置全部构造业务数据；右侧“恢复默认”仅重置需求说明。重置前可先导出留存。

## 边界

所有人员、用户事件、链接和指标均为构造或脱敏值。演示无真实采集、目标系统写入、正式权限、加密存储或后端并发控制。D1至D5评分沿用需求书V0.1建议口径，明确标为待审批；截图阈值差异及正式上线事项见技术方案讨论结论。演示不产生最终达标判断或用户服务权益决定。
